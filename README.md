# Credit Suisse home assignment

## Getting Started

I. Requirements: 
- JDK 11 
- Maven 3+ 

II. Installation and deployment steps:
2. Go to the project folder and run "mvn clean install".
3. java -jar target/drawingapp-1.0.0-SNAPSHOT.jar

Note:
It is possible to paint the canvas in the console app with
lowercase like (c 20 4 or l 1 2 6 2) .
It makes the testing easier.
